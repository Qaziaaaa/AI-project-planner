# AI Project Planner

AI-powered project planning tool with smart scheduling, task management, and productivity insights. Built with Next.js and TypeScript.

## Tech Stack

- **Framework**: Next.js 15
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **AI**: Google Gemini API

## Getting Started

1. Clone the repository
2. Install dependencies: \
pm install\
3. Set up environment variables (see .env.example)
4. Run development server: \
pm run dev\
